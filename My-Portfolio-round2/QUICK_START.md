## 🎨 CUSTOMIZE COLORS (5 MINUTES)

### Find Color Variables
Open `css/style.css`, find `:root { }` section

### Change These Lines
```css
--gold: #d4a574;              /* Change primary color */
--gold-light: #e8c5a0;        /* Change hover color */
--teal: #0dd9ff;              /* Change accent color */
--bg: #0a0e27;                /* Change background */
```

### Replace With Your Colors
```css
--gold: #YOUR-BRAND-COLOR;
--teal: #YOUR-ACCENT-COLOR;
```

Done! All colors update automatically! ✨

- Minimize external requests

## 🆘 COMMON ISSUES

### Images not showing?
```
✓ Check file paths are correct
✓ Image files exist in img/ folder
✓ Check capitalization (case-sensitive)
✓ Verify WebP support in browser
```

### Styling looks weird?
```
✓ Clear browser cache (Ctrl+Shift+Delete)
✓ Hard refresh page (Ctrl+Shift+R)
✓ Check CSS file loaded (F12 Network)
✓ Verify no conflicting styles
```

### Animations not smooth?
```
✓ Close other browser tabs
✓ Disable browser extensions
✓ Check GPU acceleration enabled
✓ Try different browser
✓ Update to latest Chrome
```

### Links not working?
```
✓ Check href URLs are correct
✓ Verify email format: mailto:email@domain.com
✓ Test link in new tab
✓ Check social profile URLs
```
