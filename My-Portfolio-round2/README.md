## 🔧 **CUSTOMIZATION GUIDE**

### Change Brand Colors
Edit `:root` variables in `css/style.css`:
```css
:root {
  --gold: #your-color;
  --teal: #your-color;
  /* More colors... */
}
```

### Adjust Animation Speed
Modify these timing variables:
```css
--transition-fast: 0.2s;
--transition-base: 0.3s;
--transition-slow: 0.5s;
```

### Update Content
- Edit text in `index.html`
- Replace profile image: `img/profile.webp`
- Update resume: `assets/resume/Syed-Azgar-Resume.pdf`
